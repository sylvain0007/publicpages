# Empower Personal Assistant — public information

Static homepage, Privacy Policy and Terms of Use for Empower Personal Assistant.

Files:
- index.html: homepage
- privacy.html: data access, recipients, retention and deletion
- terms.html: personal use conditions
- .nojekyll: static GitHub Pages configuration

## Publish with GitHub Pages

In repository Settings → Pages, choose Deploy from a branch, select main and / (root), and save. The GitHub connector does not expose Pages administration.

Expected URLs after Pages is enabled and deployment succeeds:
- https://sylvain0007.github.io/publicpages/
- https://sylvain0007.github.io/publicpages/privacy.html
- https://sylvain0007.github.io/publicpages/terms.html

These are expected destinations; GitHub Pages must be enabled before the website is available.
